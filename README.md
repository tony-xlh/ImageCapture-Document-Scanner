# ImageCapture-Document-Scanner

A Web document scanner demo using [Dynamsoft Capture Vision](https://www.dynamsoft.com/capture-vision/docs/) (`dynamsoft-capture-vision-bundle@3.6.3000`, replacing the deprecated standalone [Dynamsoft Document Normalizer](https://www.dynamsoft.com/document-normalizer/docs/introduction/?ver=latest) package) and the [ImageCapture API](https://developer.mozilla.org/en-US/docs/Web/API/ImageCapture)

[Online demo](https://tony-xlh.github.io/ImageCapture-Document-Scanner/scanner.html)

[Demo video](https://user-images.githubusercontent.com/5462205/210918076-c23f1ac3-6f56-4698-b1ae-b570f5b4f632.mp4)

Capacitor version: https://github.com/tony-xlh/capacitor-plugin-dynamsoft-document-normalizer


## Run

Serve the folder over HTTPS or `http://localhost` (camera + ImageCapture need a secure context), e.g. `python -m http.server` then open `scanner.html`.
